# Tutorial: Mi primer repositorio en GitHub Pages

Tutorial interactivo paso a paso para que estudiantes sin experiencia creen su cuenta en GitHub, suban su primera página web y la publiquen en internet con una URL real.

## Demo

**[Ver tutorial en vivo →](https://badi11a.github.io/tutoriales-primer-repositorio/)**

## ¿Qué aprende el estudiante?

Al completar el tutorial, el alumno habrá:

- Creado una cuenta en GitHub (con correo o con Google)
- Creado su primer repositorio público
- Subido un archivo `index.html` desde el navegador, sin instalar nada
- Publicado su primera página web con GitHub Pages
- Escrito su primer mensaje de commit siguiendo convenciones profesionales

## Estructura del tutorial

El tutorial se divide en 4 fases y 15 pasos secuenciales:

| Fase | Contenido | Pasos |
|------|-----------|-------|
| Parte 1 | Crear cuenta en GitHub | 1 – 5 |
| Parte 2 | Crear el repositorio | 6 – 7 |
| Parte 3 | Subir el archivo | 8 – 11 |
| Parte 4 | Publicar con GitHub Pages | 12 – 15 |

## Características técnicas

- Una sola página HTML, sin dependencias ni frameworks
- Sin imágenes — carga instantánea
- Progreso persistente en sesión con barra de avance
- Cada paso se abre automáticamente al completar el anterior
- Botón para reiniciar el tutorial desde cero
- Diseño responsivo, funciona en móvil y escritorio
- Tipografía: DM Sans + DM Mono (Google Fonts)

## Uso

No requiere instalación. Es un único archivo `index.html` autocontenido.

```bash
# Clonar el repositorio
git clone https://github.com/TU_USUARIO/NOMBRE_REPO.git

# Abrir directamente en el navegador
open index.html
```

O simplemente descarga el archivo y ábrelo con doble clic.

## Decisiones de diseño

**Sin imágenes de captura de pantalla.** La interfaz de GitHub cambia con frecuencia. En lugar de capturas que quedan desactualizadas, el tutorial usa nombres de botones y etiquetas en `code` que son más estables y duraderos.

**Contexto del "por qué".** Cada paso explica el concepto detrás de la acción (qué es un repositorio, qué es un commit, por qué importa el nombre de usuario) para que el alumno comprenda, no solo ejecute.

**Gestión de bifurcaciones.** El tutorial advierte explícitamente qué pasos aplican según si el registro se hizo con correo o con Google, evitando que el alumno busque un correo de verificación que nunca llegará.

## Contexto académico

Desarrollado como material de apoyo para estudiantes que están dando sus primeros pasos en desarrollo web. Diseñado para usarse en la primera sesión de un curso, antes de instalar cualquier herramienta local.
