Tutorial: Mi primer repositorio en GitHub y publicación con GitHub Pages

Mi primer repositorio

En este tutorial vas a crear una cuenta en GitHub, subir tu primera página web y publicarla en internet. Al terminar tendrás una URL real que puedes compartir con cualquier persona.

Parte 1 · Crear tu cuenta en GitHub
1

Ir a github.com

Tu punto de partida: la página principal de GitHub.

GitHub es la plataforma más usada en el mundo para guardar y compartir código. Piensa en ella como una nube especializada para proyectos de desarrollo. La interfaz está en inglés — no existe opción de cambiarla al español, así que iremos conociendo los términos clave a medida que avancemos.

Acción

Abre tu navegador y ve a github.com. Haz clic en el botón Sign up que aparece arriba a la derecha.

2

Ingresar tu correo electrónico

El correo es la llave de tu cuenta.

GitHub usará este correo para enviarte un código de verificación y para notificarte sobre tu cuenta. Usa un correo que revises con frecuencia — sin verificarlo no podrás crear repositorios.

Alternativa nueva 2024+

También puedes hacer clic en Continue with Google para registrarte directamente con tu cuenta de Google, sin necesidad de recordar una contraseña adicional.

3

Elegir contraseña y nombre de usuario

Tu nombre de usuario es tu identidad pública como desarrollador.

El nombre de usuario aparecerá en la URL de todos tus proyectos. Por ejemplo, si tu usuario es maria-dev, tu sitio quedará en maria-dev.github.io. Elige algo profesional y fácil de recordar — este nombre te acompañará en tu carrera.

Evita números aleatorios o apodos informales. Muchos reclutadores revisan el perfil de GitHub como parte del proceso de selección.

4

Resolver el captcha visual

GitHub verifica que eres una persona real.

GitHub presenta un rompecabezas visual que debes completar antes de continuar. Es una medida de seguridad para evitar que robots creen cuentas falsas de forma masiva.

Acción

Haz clic en Start puzzle y sigue las instrucciones en pantalla para resolver el desafío.

5

Ingresar el código de verificación

El último paso para activar tu cuenta.

GitHub envía un código de 8 dígitos al correo que ingresaste. Debes copiarlo y pegarlo en la pantalla para confirmar que el correo es tuyo. Este proceso se llama verificación de correo y es estándar en la mayoría de las plataformas web.

¿No llegó el correo? Revisa la carpeta de spam o correo no deseado. Si tampoco está ahí, puedes solicitar que te lo reenvíen desde la misma pantalla.

Parte 2 · Crear tu repositorio
6

Crear un nuevo repositorio

Un repositorio es la carpeta de tu proyecto en la nube.

Un repositorio (o "repo") es donde vive tu proyecto en GitHub. Contiene todos tus archivos y el historial de cambios. Puedes tener tantos repositorios como proyectos quieras — y todos son gratuitos si son públicos.

Acción

En la pantalla principal haz clic en el botón verde New o en el ícono + en la barra superior y selecciona New repository.

7

Nombrar el repositorio y marcarlo como público

El nombre define la URL final de tu sitio.

El nombre del repositorio formará parte de la URL de tu página publicada. Si lo llamas hola-mundo, tu sitio quedará disponible en tu-usuario.github.io/hola-mundo. Además, debe ser público para que GitHub Pages funcione con una cuenta gratuita — los repositorios privados no se pueden publicar.

Acción

Escribe hola-mundo en el campo Repository name. Selecciona la opción Public y haz clic en Create repository.

Usa guiones en lugar de espacios en el nombre. Los espacios no se permiten en URLs.

Parte 3 · Subir tu archivo
8

Seleccionar "uploading an existing file"

GitHub te permite subir archivos directamente desde el navegador.

Al crear el repositorio, GitHub muestra una pantalla vacía con varias opciones para agregar archivos. La más sencilla, sin necesidad de instalar nada, es subir el archivo directamente desde tu computador usando el enlace de carga.

Acción

En la pantalla del repositorio vacío, busca y haz clic en el enlace que dice uploading an existing file.

9

Arrastrar o seleccionar index.html

El archivo debe llamarse exactamente así.

GitHub Pages busca automáticamente un archivo llamado index.html para mostrarlo como la página principal. Si el archivo tiene otro nombre, el sitio no funcionará correctamente. Puedes arrastrarlo directamente a la zona de carga o hacer clic para buscarlo en tu computador.

El nombre debe ser exactamente index.html — todo en minúsculas, sin espacios. Una mayúscula o un espacio puede hacer que el sitio no cargue.

10

Escribir un mensaje de commit descriptivo

El commit es el registro oficial del cambio que estás haciendo.

Un commit es como una fotografía del estado de tu proyecto en un momento específico. El mensaje que escribes describe qué cambiaste y por qué. Este historial es muy valioso: te permite saber qué se hizo, cuándo y quién lo hizo — especialmente cuando trabajas en equipo.

Buena práctica

Escribe algo descriptivo como Agrega página principal hola mundo. Evita mensajes vagos como "cambios" o "update".

La convención más usada es escribir el mensaje como una instrucción en presente: "Agrega", "Corrige", "Actualiza". Así se lee como un registro de acciones.

11

Hacer clic en "Commit changes"

Confirmas y guardas el archivo en el repositorio.

Al hacer clic en Commit changes, el archivo queda guardado oficialmente en tu repositorio. GitHub registra quién hizo el cambio, cuándo y con qué mensaje. Desde este momento, el archivo vive en la nube y puedes acceder a él desde cualquier dispositivo.

Parte 4 · Publicar con GitHub Pages
12

Ir a Settings → Pages

Aquí activarás la publicación de tu sitio.

GitHub Pages es un servicio gratuito que convierte tu repositorio en un sitio web real con una URL pública. Para activarlo debes entrar a la configuración del repositorio y habilitarlo manualmente — no se activa solo.

Acción

Dentro de tu repositorio, haz clic en la pestaña Settings (arriba a la derecha). En el menú izquierdo, busca y haz clic en Pages.

13

Seleccionar rama main y carpeta / (root)

Le indicas a GitHub desde dónde servir tu sitio.

GitHub necesita saber desde qué parte de tu repositorio publicar. La rama main es la principal (donde están tus archivos) y / (root) significa la raíz — es decir, la carpeta principal del proyecto, justo donde subiste tu index.html.

Acción

En la sección Branch, selecciona main en el primer desplegable y / (root) en el segundo. Haz clic en Save.

14

Esperar ~2 minutos

GitHub está preparando y desplegando tu sitio.

Después de guardar, GitHub inicia un proceso automático llamado "deployment" (despliegue): toma tus archivos, los procesa y los publica en sus servidores. Este proceso demora entre 1 y 3 minutos. Puedes ver el estado del despliegue en la misma sección de Pages — aparecerá un ícono naranja mientras procesa y verde cuando esté listo.

15

Visitar tu sitio publicado

Tu primera página web está en internet.

Una vez desplegado, tu sitio tiene una URL pública real que puedes compartir con cualquier persona del mundo. Esta URL sigue el formato https://tu-usuario.github.io/hola-mundo. Desde este momento, cada vez que subas un cambio al repositorio, el sitio se actualizará automáticamente.

Tu URL

Abre una nueva pestaña y escribe: https://TU_USUARIO.github.io/hola-mundo

¿No carga? Espera un par de minutos más y recarga la página con F5. GitHub a veces tarda un poco más en la primera publicación.

Tutorial completado

Creaste tu cuenta, subiste tu primer archivo y publicaste tu primera página en internet. Ese es el flujo base que usarás en todos tus proyectos.
